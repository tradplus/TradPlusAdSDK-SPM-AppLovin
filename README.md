# TradPlus AppLovin Adapter Swift Package

Swift Package Manager support for the TradPlus AppLovin adapter (15.12.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-AppLovin.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-AppLovin.git", exact: "15.12.0")
```

Third-party dependency: AppLovin SDK `13.6.3`.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.12.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
